# Generated implementation evidence

Phase agents place sanitized, reproducible environment/capability reports here. Generated evidence is versioned when it is necessary to explain compatibility, but it must not contain:

- credentials, cookies, authorization headers, or environment dumps;
- personal usernames, emails, account/organization IDs;
- real provider session IDs;
- absolute home/profile paths;
- proprietary source code or unreviewed provider output.

`provider-capabilities.example.json` is a shape example only. Phase 0 creates `provider-capabilities.json` from observed evidence and documents sanitization.

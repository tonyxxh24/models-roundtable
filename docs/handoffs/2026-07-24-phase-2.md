## Outcome first

The provider-neutral local chat MVP is complete and uses only the deterministic
in-process fake adapter. A local owner can create/switch rooms, mention one or
both fake agents, see coalesced streaming text, stop and retry a run, inspect the
exact context manifest, reconnect with durable replay and active-run snapshots,
search with FTS snippets, and export canonical JSON or Markdown. SQLite retains
rooms, independent provider sessions, events, partial output, and recovery state.

Phase 3 is not ready to implement: the Phase 0 automated identity could not run
Codex, so its required GO capability decision and sanitized fixtures do not exist.

## Decisions and deviations

- ADRs referenced: ADR-0005 (explicit routing) and ADR-0008 (no hidden model calls).
- No direct OpenAI/Anthropic API, provider CLI, credentials, workspace writes, or
  non-loopback listener were introduced.
- The Phase 2 concurrency ceiling is deliberately one run at a time. This is a
  valid bounded global limit and inherently serializes each fake provider session;
  later phases may safely raise it.
- Axe runs structural rules in jsdom with `color-contrast` disabled because jsdom
  has no canvas/layout engine. Keyboard behavior is exercised through real DOM
  events; visual contrast remains a manual browser check before release candidate.
